# Investor Materials

Create investor-ready materials: pitch decks, one-pagers, and financial projections.

## Steps
1. **Intake** — gather company info, stage, ask, metrics, and narrative
2. **Structure** — apply standard pitch deck framework:
   - Problem → Solution → Market → Traction → Team → Business Model → Ask
3. **Draft deck** — 12-slide structure with one key point per slide
4. **One-pager** — single-page executive summary
5. **Financial model** — if requested, build basic projections (revenue, costs, runway)
6. **Review** — verify all numbers are internally consistent

## 12-Slide Structure
1. Title + tagline
2. Problem
3. Solution
4. Demo/product
5. Market size (TAM/SAM/SOM)
6. Business model
7. Traction/metrics
8. Competition/differentiation
9. Team
10. Go-to-market
11. Financial projections
12. Ask + use of funds
