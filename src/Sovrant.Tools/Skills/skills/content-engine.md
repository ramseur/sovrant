# Content Engine

Take a single piece of anchor content and repurpose it across multiple platforms.

## Steps
1. **Ingest anchor** — read and understand the source content (article, talk, thread)
2. **Extract key points** — identify 3-5 core ideas and supporting evidence
3. **Platform adaptation** — create platform-specific versions:
   - **X/Twitter** — thread (5-10 tweets), or single punchy tweet
   - **LinkedIn** — professional narrative post (200-300 words)
   - **Newsletter** — email-friendly digest with personal angle
   - **Blog** — expanded version with SEO considerations
4. **Review** — verify each version maintains the core message

## Rules
- Each platform version must stand alone (don't assume reader saw the others)
- Match platform conventions (hashtags for X, professional tone for LinkedIn)
- Vary the hook/opener across platforms — never copy-paste the same opening
- Include a CTA appropriate to each platform
