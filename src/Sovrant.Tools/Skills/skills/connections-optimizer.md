# Connections Optimizer

Analyse and optimise a professional network for strategic value.

## Steps
1. **Audit** — review current network (from provided contacts or description)
2. **Categorise** — group contacts by:
   - Strategic value (high/medium/low)
   - Relationship strength (strong/weak/dormant)
   - Domain relevance (industry, function, geography)
3. **Identify gaps** — missing connections for goals (investors, customers, advisors, talent)
4. **Prune** — flag low-value/dormant connections for archiving
5. **Expand** — suggest specific people or types of connections to add
6. **Outreach** — draft warm re-engagement messages for dormant high-value contacts

## Output Format
- **Network health score** — diversity, depth, gap analysis
- **Top connections** — ranked by strategic value
- **Recommended additions** — specific types with reasoning
- **Re-engagement drafts** — personalised messages for top dormant contacts
