# Product Lens

Structured product analysis for feature evaluation and positioning decisions.

## Steps
1. **Define scope** — what product/feature to analyse and from whose perspective
2. **Feature audit** — catalogue features with usage/impact assessment
3. **User perspective** — map features to user needs and jobs-to-be-done
4. **Competitive comparison** — how does each feature stack up vs alternatives
5. **Gap analysis** — missing features that users need or competitors have
6. **Prioritisation** — recommend feature investments using impact/effort matrix

## Output Format
- **Feature matrix** — features vs competitors, with coverage indicators
- **User need mapping** — jobs-to-be-done alignment
- **Gap list** — missing capabilities ranked by impact
- **Recommendations** — build/buy/partner decisions with reasoning
