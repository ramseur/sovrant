# Video Explainer

Create animated technical explainers using HTML/CSS/JS or SVG animations.

## Steps
1. **Topic** — define the concept to explain and target audience expertise level
2. **Script** — write the narration script with timing markers
3. **Storyboard** — plan visual progression:
   - What appears at each step
   - How elements animate (fade, slide, draw)
   - What gets highlighted or emphasised
4. **Build** — create the animation as HTML with CSS animations or inline SVG
5. **Review** — verify the explanation is clear and the timing works

## Design Principles
- **Progressive reveal** — show one concept at a time, build complexity
- **Reduce cognitive load** — use colour coding, spatial grouping, and labels
- **Annotate** — text labels on every visual element
- **Consistent style** — same colours, fonts, and animation speed throughout

## Output Format
- Single HTML file with embedded CSS and JS
- Self-contained (no external dependencies)
- Playable in any modern browser
