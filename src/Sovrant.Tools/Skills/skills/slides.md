# Slide Deck Creation

Create structured presentation decks as HTML or Markdown slides.

## Steps
1. **Brief** — confirm topic, audience, duration, and key message
2. **Outline** — plan slide structure (title, sections, conclusion)
3. **Content** — write each slide with:
   - One key idea per slide
   - Supporting visual or data reference
   - Speaker notes
4. **Flow** — ensure narrative arc and smooth transitions
5. **Deliver** — output as markdown sections or HTML reveal.js format

## Slide Guidelines
- **Title slide** — topic, presenter, date
- **Problem/context** — why this matters (1-2 slides)
- **Core content** — 5-10 slides, one point each
- **Summary** — key takeaways (1 slide)
- **CTA/next steps** — what the audience should do (1 slide)

## Rules
- Maximum 6 bullet points per slide
- No walls of text — if it's more than 30 words, split the slide
- Every slide should answer: "What should the audience remember from this?"
- Include speaker notes with talking points
