What v2 changes

  • Remove the wordmark TextBlock from the rail's brand row in MainWindow.axaml. Title="Sovrant" stays — it feeds the titlebar, taskbar, and Alt-Tab.
  • Mark 34px → 44px, radius 9px → 12px, glyph 15px → 21px; brand row 60px → 68px.
  • Collapsed rail simplifies — the mark centers in the 76px column with no wordmark to hide.
  • Nothing else moves: 40px rows, 19px icons at 1.9 stroke, tint + 3px accent bar, Admin's four groups.

Open questions for this pass

  • The mark is a letter, not a logo. v2 makes it the only brand element on screen, which raises the bar for drawing a real one.
  • Content panes are still undesigned. Every screen behind these six groups — and Login — needs its own pass. That work is next.
  • LoginWindow duplicates the name the same way (Title="Sovrant — Sign in" plus a 28px heading) and binds {DynamicResource BackgroundBrush}, a key that exists in neither theme file.
