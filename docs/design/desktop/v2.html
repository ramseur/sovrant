What v2 changes

  • Remove the wordmark TextBlock from the rail's brand row in MainWindow.axaml. The window's Title="Sovrant" stays — it's the one that feeds the titlebar, taskbar, and Alt-Tab.
  • Mark grows 34px → 44px, corner radius 9px → 12px, glyph 15px → 21px. At 34px next to 15.5px text it read as an afterthought; alone at 44px it reads as the logo.
  • Brand row 60px → 68px so the larger mark keeps breathing room above and below.
  • Collapse toggle keeps its position and behaviour; with the word gone it simply sits closer to the mark.
  • Collapsed rail gets simpler, not more complex — the mark centers in the 76px column and the toggle moves below it, instead of hiding a wordmark that no longer exists.

Open questions for this pass

  • The mark is a letter, not a logo. It's an "S" in a rounded purple square — fine as a placeholder, but v2 makes it the sole brand element on the screen, which raises the bar. Worth deciding whether a real mark gets drawn before this ships.
  • Web matches. The browser tab is Web's equivalent of the OS titlebar — it already carries the page title — so the same rule holds: name the product in the chrome the platform owns, show only the mark in the rail. Applied in web/v2.
  • LoginWindow has the same duplication (Title="Sovrant — Sign in" plus a 28px "Sovrant" heading) and needs the same decision — covered next in the Login pass.
