What shipped

  • Horizontal icon-only row + separate collapsed strip replaced with one vertical group-nav list (icon+label expanded, icon-only collapsed) — single source in MainWindow.axaml for both states.
  • Emoji Content="📊" buttons replaced with stroke-based StreamGeometry icons in NavIcons.axaml, reusing the exact same path data as Web's inline SVGs — Avalonia's geometry mini-language turned out to be SVG-compatible, arcs included.
  • New BrandPrimarySoft theme token (both SovrantDarkColors.axaml and SovrantLightColors.axaml) for the tinted active background, matching Web's color-mix tint.
  • Admin's 9 items grouped identically to Web: Overview / Access / Safety / System.

Two Avalonia-specific bugs — watch for these in future screens

  • Missing VerticalContentAlignment="Center" on a Button left single-line text pinned to the top of its row instead of centered — looked like "too much space between items" until the property was added everywhere.
  • A Button needs an explicit Height, not just a stretch-filled parent Grid — otherwise FluentTheme's :pointerover hover chrome renders visibly shorter than the button's real bounds, even though the bound active-state Background fills correctly. Confirmed by direct pixel comparison; fixed by mirroring the explicit-height pattern the sub-panel buttons already used successfully.
