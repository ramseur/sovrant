What v3 changes

  • Matches Web exactly — 56px mark, 20px wordmark, 40px inputs at 9px radius, 44px primary button. Needs explicit Height, CornerRadius, and Padding on the Avalonia controls; the stock theme won't produce these on its own.
  • Sign in becomes a brand-filled button, not the default grey — it's the primary action on the screen and currently doesn't look like it.
  • Busy moves onto the button — spinner plus "Signing in…", replacing the detached ProgressBar at the bottom.
  • Separator becomes a labelled rule that reads "Don't have an account?" inline, matching Web.
  • Window 420×460 → 440 wide, height driven by content, still non-resizable.

Bugs to fix while implementing

  • BackgroundBrush doesn't exist. LoginWindow.axaml line 11 binds {DynamicResource BackgroundBrush}; neither theme file defines that key. DynamicResource fails silently, so the window never receives its themed background. Should be SurfaceBackground.
  • Error text is Foreground="Red", hardcoded — ignores the theme and isn't the StatusFail red used everywhere else.
  • Why the wordmark stays here but not in the rail. v2 removed it from the rail because the rail is persistent chrome sitting directly under a titlebar that already names the app — the repetition accumulates all day. Login is a one-time screen with no rail, and it's where the product introduces itself. Different context, different answer; worth disagreeing with, but not an accident.
  • The mark is still a letter — at 56px, dead centre, the first thing a new user sees.
