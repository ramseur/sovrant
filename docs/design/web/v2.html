What v2 changes

  • Drop .rail-brand-text from MainLayout.razor; grow .rail-brand-icon to 44px / 12px radius and the brand row to 68px in sovrant.css.
  • The <title> already renders "Sovrant" in the tab — the name survives without the rail repeating it.
  • The brand row stays a clickable home link — only its contents change.
  • Favicon should be the same mark, so tab and rail agree.

Open questions for this pass

  • The mark is a letter, not a logo — an "S" in a rounded purple square, now the only brand element on screen on both platforms.
  • Two parity gaps above — Web's 42px nav rows against Desktop's 40px, and the footer showing email + workspace on Web but username + role on Desktop. Both are small; both are the difference between "same design" and "same design, roughly".
  • Content panes are still undesigned. Every screen behind these six groups — and Login — needs its own pass. That work is next.
