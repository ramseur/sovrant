What v3 changes

  • Mark leads, wordmark supports. A 56px mark above a 20px wordmark, replacing the bare 26px text heading.
  • On the shell's scale. Inputs 40px at 9px radius, primary button 44px, card 400px / 14px radius / 32px padding — replacing 5px radii, ~34px inputs, and a 360px card.
  • Focus is visible. Brand border plus a 3px ring — today .login-input:focus only shifts the border color, which is easy to miss.
  • Error gets an icon and keeps the existing token-based red, so it reads as a state rather than just red text.
  • Busy is on the button — spinner plus "Signing in…" where the user is already looking, instead of a detached 3px bar at the bottom of the card.
  • Password reveal toggle — new, and the one place a long password typo is worth catching before submit.

Found while designing this

  • Desktop binds a resource key that doesn't exist. LoginWindow.axaml sets Background="{DynamicResource BackgroundBrush}"; neither SovrantDarkColors.axaml nor SovrantLightColors.axaml defines BackgroundBrush. DynamicResource fails silently, so the window never gets its themed background. Should be SurfaceBackground.
  • Desktop hardcodes Foreground="Red" for the error text instead of the StatusFail token, so it ignores the theme and misses the red the rest of the product uses.
  • Theme on a fresh machine. App.razor hardcodes data-theme="dark" and JS overrides it from localStorage. Login runs before any user preference is loaded, so it shows whatever the browser last stored — worth deciding whether it should follow prefers-color-scheme instead.
  • The mark is still a letter. At 56px, dead centre, first thing a new user sees — this screen is the strongest argument yet for drawing a real one.
