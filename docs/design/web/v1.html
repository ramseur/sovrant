What shipped

  • One rail instead of two stacked components — RailNav.razor and Sidebar.razor now compose into a single collapsible shell in MainLayout.razor.
  • Emoji glyphs replaced with inline SVG stroke icons at 19px, matching Desktop's NavIcons.axaml path data.
  • Collapsed rail is 76px; expanded is 300px.
  • Active item gets a left accent bar in --brand-primary plus a soft tint background, not full-strength fill.
  • Admin's 9 items grouped: Overview (Command Center) · Access (Users, Workspaces, Providers) · Safety (Governance, Trust Boundary) · System (Diagnostics, Platform/System Integrations).
  • Every color is a token already in sovrant.css — no new palette introduced.

Bug caught during design, fixed before shipping

  • Flexbox row collapse: sub-nav rows need flex-shrink: 0 inside their scrolling flex column. Without it, once a long list (Admin's 9 items) overflows its container, every row silently collapses to 0px height instead of the container scrolling — caught in this very design-preview stage before it ever reached real code, then deliberately built into the shipped CSS from the start.
  • No route or data-model changes — same six destinations, same session store, same admin gating as before.
